## 1. 초기 코드베이스 분석

### 1.1 진입점 확인

- `src/` 디렉토리에는 `src/index.js` 파일 하나만 존재했음.
- `package.json`의 `"main"` 필드는 루트의 `index.js`를 가리키지만, 실제 루트 `index.js` 파일은 없었음.
- 따라서 실행 시 `node src/index.js`로 직접 지정해야 하는 상태였음.

### 1.2 함수 호출 관계

- `extractEmails`, `isValidEmail` 함수는 `src/index.js`에 **정의만** 되어 있었고, 프로젝트 내 어디에서도 **호출되지 않았음**.
- 두 함수는 서로 연결되어 있지 않았음.

### 1.3 초기 데이터 흐름

```
src/index.js 로드
  ├─ 1행: 문자열 리터럴 "console.log('hello cursor');" (실행되지 않음)
  ├─ extractEmails(users)  → 정의만 존재, 호출 없음
  └─ isValidEmail(email)   → 정의만 존재, 호출 없음
```

| 함수 | 입력 | 처리 | 출력 |
|------|------|------|------|
| `extractEmails` | `users` 배열 | 각 `user.email` 추출 | 이메일 문자열 배열 (비배열 입력 시 `[]`) |
| `isValidEmail` | `email` 문자열 | 정규식 `/^[^\s@]+@[^\s@]+\.[^\s@]+$/` 검사 | `true` / `false` |

## 2. 이메일 모듈 분리 (`src/email.js` 생성)

### 2.1 작업 내용

`src/index.js`에 있던 `extractEmails`, `isValidEmail` 함수를 `src/email.js`로 분리함.

### 2.2 분리된 함수

**`extractEmails(users)`**
- 사용자 배열에서 `email` 필드만 추출.
- 배열이 아닌 입력은 빈 배열 `[]` 반환.

**`isValidEmail(email)`**
- 문자열 타입이 아니면 `false` 반환.
- 기본 이메일 형식 정규식으로 유효성 검사.

### 2.3 export

```javascript
module.exports = { extractEmails, isValidEmail, getValidEmails };
```

## 3. `getValidEmails` 함수 추가

### 3.1 목적

`extractEmails`와 `isValidEmail`을 결합하여, 사용자 배열에서 **유효한 이메일만** 추출하는 함수 추가.

### 3.2 구현

```javascript
function getValidEmails(users) {
    return extractEmails(users).filter(isValidEmail);
}
```

### 3.3 데이터 흐름

```
users (배열)
  │
  ▼
extractEmails(users)  →  [email1, email2, email3, ...]
  │
  ▼
.filter(isValidEmail)  →  [유효한 email만]
  │
  ▼
getValidEmails 결과 반환
```

## 4. `src/index.js` 정리

### 4.1 변경 전

- 이메일 관련 함수 2개가 `index.js`에 직접 정의되어 있었음.
- 첫 줄이 문자열 리터럴(`"console.log('hello cursor');"`)로 되어 있어 실제 출력되지 않았음.

### 4.2 변경 후

```javascript
console.log('hello cursor');

const { getValidEmails } = require('./email');

module.exports = { getValidEmails };
```

- 이메일 로직은 `email.js`로 위임.
- `getValidEmails`만 re-export.
- `console.log`가 실제로 실행되도록 수정.

## 5. 테스트 작성 (`src/email.test.js`)

### 5.1 테스트 프레임워크

- Node.js 내장 테스트 러너(`node:test`)와 `node:assert/strict` 사용.
- 별도 npm 패키지 설치 없이 동작.

### 5.2 테스트 케이스 (6개)

| # | 테스트명 | 검증 내용 |
|---|----------|-----------|
| 1 | `extractEmails returns emails from user array` | 사용자 배열에서 이메일 추출 |
| 2 | `extractEmails returns empty array for non-array input` | `null`, `undefined` 입력 시 `[]` 반환 |
| 3 | `isValidEmail accepts valid addresses` | 유효한 이메일 `true` 반환 |
| 4 | `isValidEmail rejects invalid addresses` | 잘못된 형식, 빈 문자열, `null` → `false` |
| 5 | `getValidEmails returns only valid emails` | 유효한 이메일만 필터링 |
| 6 | `getValidEmails returns empty array for non-array input` | 비배열 입력 시 `[]` 반환 |

### 5.3 테스트 실행 방법

```bash
npm test
```
